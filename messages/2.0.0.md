TokensCounter 2.0.0
==================

The plugin now explicitly runs in Sublime Text's Python 3.14 host.
Sublime Text build 4205 or newer and Package Control 4 are required.
Dependencies are requested only on compatible Sublime Text builds.

Settings continue to load from TokensCounter.sublime-settings.
The default model is gpt-4o. To select tokenizer_encoding explicitly,
set model_name to null; otherwise the model takes precedence.
